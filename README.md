# Fortress Arena

Браузерный 3D-шутер в духе **Team Fortress 2** — играется прямо в браузере, без установки.
Девять классов, боты с разными ролями, ракетные прыжки, турели, липкие бомбы, убер-заряд,
маскировка шпиона и захват контрольных точек.

```
npm install      # нужен только для three.js (скопирован в vendor/)
npm start        # http://localhost:8080/tf2/
npm test         # 126 автотестов: игровая логика + клиент
```

Игра: **`/tf2/`** (index.html).

---

## Что внутри

**9 классов** — у каждого своя модель, оружие, скорость и роль:

| Класс | HP | Скорость | Оружие | Особенность |
|---|---|---|---|---|
| Разведчик | 125 | 8.6 | Двухстволка, бита | Разброс растёт при стрельбе очередью |
| Солдат | 200 | 5.6 | Ракетница, лопата | **Ракетные прыжки**, 4 ракеты в обойме |
| Поджигатель | 175 | 6.4 | Огнемёт, топор | Поджигает, **отражает снаряды** сжатым воздухом (ПКМ) |
| Подрывник | 175 | 6.0 | Гранатомёт, липучки | Ручная детонация липучек (G) |
| Пулемётчик | 300 | 5.0 | Пулемёт Sasha | Раскрутка ствола, замедление при стрельбе |
| Инженер | 125 | 6.6 | Дробовик, гаечный ключ | **Турель** (3 уровня), **раздатчик**, **телепорт** |
| Медик | 150 | 7.0 | Арбалет, медган | Лечит, копит **убер-заряд** (E) — неуязвимость |
| Снайпер | 125 | 6.6 | Винтовка, ПП | Заряд при удержании, **хедшот ×3** |
| Шпион | 125 | 6.8 | Револьвер, нож | **Невидимость** (C), **маскировка** (V), удар в спину |

**Карты:** «Ущелье» (центральная башня, мост, бункеры) и «Двор» (тесный симметричный двор).
На каждой — две контрольные точки: удерживайте зону 14 секунд, чтобы захватить её и принести очко команде.
Раунд идёт 8 минут, побеждает команда с большим числом захватов.

## Управление

| Клавиши | Действие |
|---|---|
| WASD | движение |
| Мышь | обзор |
| ЛКМ | основное оружие |
| ПКМ | вторичное (прицел снайпера / поджиг пиро / медган медика) |
| Пробел / Shift | прыжок / присесть |
| R, 1–3, Q, колесо | перезарядка, слоты оружия, прошлое оружие |
| G | детонация липучек (подрывник) |
| E | убер-заряд (медик) |
| C, V | невидимость и маскировка (шпион) |
| 4/5/6, F, X | выбрать/поставить/отменить постройку (инженер) |
| Tab / M / Esc | счёт, смена класса, пауза |
| K | «киллбайнд» (самоуничтожение) |

Если браузер запрещает захват курсора (например, игра открыта во фрейме без разрешения
`pointer-lock`), игра сама переключается в запасной режим: обзор работает обычным движением
мыши над окном, стрельба — по клику.

## Как устроено

```
tf2/
  index.html, style.css     интерфейс, меню, HUD
  src/
    data.js                 классы, оружие, карты, тюнинг физики
    map.js                  построение карты из описания
    physics.js              AABB-коллизии, лучи, векторы (без three.js)
    world.js                игровой мир: урон, снаряды, постройки, захват
    bots/ai.js              ИИ ботов: 9 ролей, восприятие, навигация
    models.js               модели бойцов/оружия/построек (low-poly)
    render.js               сцена three.js, эффекты, камера, вид от 1-го лица
    audio.js                синтез звуков через WebAudio (без файлов)
    input.js                клавиатура/мышь → команда игрока
    hud.js                  здоровье, патроны, точки, киллфид, счёт
    main.js                 меню, раунд, игровой цикл (фиксированный шаг 60 Гц)
  test/
    smoke.mjs               тесты ядра: физика, оружие, турели, боты (68 проверок)
    client.mjs              тест клиента с заглушками three.js и DOM (58 проверок)
    stub-three.mjs, dom.mjs заглушки для тестов
vendor/                     three.js (ESM-сборка, раздаётся локально)
server.js                   статический сервер без зависимостей
```

Ключевое архитектурное решение: **вся игровая логика (`data/map/physics/world/bots`) не зависит от
three.js и DOM**. Поэтому ботов, урон, турели и захват точек можно прогнать в Node — что и делает
`npm run test:game`. А `npm run test:client` подменяет three.js и DOM заглушками и прогоняет
настоящий клиентский код (рендер, HUD, ввод, игровой цикл), отлавливая опечатки и ошибки API.

## Тесты

```
npm test
```

* `test:game` — физика (падение, стены, прыжки), ракетные прыжки, хедшоты, удар в спину,
  липучки, медган и убер, турель/раздатчик/телепорт, огнемёт и отражение, захват точек,
  а также **полный матч 8 ботов на 2.5 минуты** (проверки на NaN, зависания, «мёртвый» ИИ,
  производительность: ~90x реального времени).
* `test:client` — загрузка игры, меню, старт раунда, ввод и стрельба, HUD для всех 9 классов,
  способности (постройки, убер, невидимость, маскировка, прицел), смерть и возрождение,
  пауза, настройки, конец раунда, соответствие id в HTML и JS.

## Производительность

Игра рассчитана на обычный ноутбук: блочные модели, без внешних ассетов, партиклы ограничены
(~400 одновременно), тени можно выключить в настройках. Физика и логика идут фиксированным шагом
60 Гц, рендер — по частоте кадров.

## Лицензия

Код — для свободного использования. Team Fortress 2 — торговая марка Valve; это неофициальная
фанатская игра, все модели и звуки сгенерированы кодом.
